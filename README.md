# Talks

## The problem

A talk disappears after the room empties unless the slides and the argument live somewhere durable. Conference links rot; memory is not a archive.

**What this repo does:** it keeps a public archive of talks by [Sean Murray](https://github.com/seancmry) (`seancmry`). Each folder has slides plus a **Remarks** write-up so you can follow the argument even if you were not there.

## Who it helps

- People who saw a talk and want the slides / notes again  
- People who missed it and still want the idea in plain language  
- Organisers linking materials from a programme page  

## How to run / browse

No install. Open a talk folder and start with its README.

| Talk | Length | Start here |
|---|---|---|
| [AI Automation vs. Legacy APIs: The Hidden Contracts Behind "The API Broke"](./2026-06-hidden-contracts/) | ~10–12 min | [README](./2026-06-hidden-contracts/README.md) · [Slides](./2026-06-hidden-contracts/Hidden_Contracts_Slides.html) · [Remarks](./2026-06-hidden-contracts/REMARKS.md) |

There is also a small live demo under that talk’s `demo/` folder (see its README for how to run).
